📥 앱 내려받기 (안드로이드)
카카오톡에서 이 화면을 여셨다면, 우측 상단 ⋮ → 다른 브라우저로 열기(크롬)를 누른 뒤 내려받아 주세요. 카톡 안에서는 설치 파일이 받아지지 않습니다.

설치 방법

  1. 위 버튼을 눌러 내려받기
  2. 알림창(또는 다운로드 폴더)에서 받은 파일 열기
  3. “출처를 알 수 없는 앱” 안내가 뜨면 허용 (최초 1회)
  4. 설치 → 홈 화면에 🚕 K창택시 아이콘 생성

설치 후 팀 공지의 가입 코드로 가입하고, 사인을 한 번만 등록하면 끝입니다.
